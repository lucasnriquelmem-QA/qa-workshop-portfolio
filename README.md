# QA Workshop & Automation Portfolio

Este repositorio contiene los entregables del QA Workshop original junto con la implementación de un Framework de Automatización profesional para la aplicación PetStore.

## Stack Tecnológico de Automatización
* **Lenguaje:** Python
* **Herramienta UI/API:** Playwright (Async API)
* **Framework de Pruebas:** Pytest
* **Patrón de Diseño:** Page Object Model (POM)

## Cómo ejecutar las pruebas locales

1. Clonar el repositorio.
2. Instalar las dependencias necesarias:
   ```bash
   pip install -r requirements.txt
   ```
3. Ejecutar las pruebas de UI:
   ```bash
   pytest automation_ui/tests/
   ```
